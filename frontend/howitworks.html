How It Works

1. Report a Missing Person

Family members or concerned citizens can submit a report with personal details and a recent photo. The photo is uploaded to Cloudinary and a face encoding is generated.

2. AI‑Powered Face Matching

Our backend uses the face_recognition library (or a mock fallback) to compare the uploaded encoding against a database of registered family members. When a match is found, a confidence score is returned.

3. Real‑Time Notifications

Matched cases trigger an in‑app notification and optional email/SMS alerts so families are instantly informed.

4. Admin Review

Admins can approve, reject, or delete reports, manage users, and monitor system health.
